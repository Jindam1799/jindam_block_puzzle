JD CHINESE · HSK 블록퍼즐 — 실행 방법
=====================================

[컴퓨터에서 항상 크롬으로 열기]
- Windows : PLAY_Chrome_Windows.bat 더블클릭
            MAKE_DESKTOP_ICON_Windows.bat 를 한 번 실행하면
            바탕화면에 게임 아이콘(항상 크롬으로 열림)이 생깁니다.
- Mac     : PLAY_Chrome_Mac.command 더블클릭
            (처음 한 번은 우클릭 → 열기)

[폰·패드에서 앱 아이콘으로 쓰기]  ※ 폴더 전체를 https 주소로 올렸을 때
- 안드로이드 크롬 : 로비의 [📲 앱으로 설치] 또는 메뉴 → 홈 화면에 추가
- 아이폰/아이패드 : 공유 버튼 → 홈 화면에 추가
- 카카오톡·네이버·인스타 등 앱 안에서 링크를 열면
  안드로이드는 자동으로 크롬으로 다시 열리고, 아이폰은 크롬으로 열기 버튼이 나옵니다.

[음성]
- Tingting(애플 기기 음성)을 가장 먼저 사용합니다.
- Tingting이 없는 기기(윈도우·안드로이드)는 가장 비슷한 중국어 여성 음성으로 자동 대체합니다.
- 로비 아래 '🔊 음성' 버튼을 누르면 지금 쓰는 음성을 확인하고 들어볼 수 있습니다.

[파일 구성]
index.html / style.css / scripts.js / data.js  : 게임 본체
manifest.webmanifest / sw.js / icons/          : 앱 아이콘·설치용
*.mp3                                          : 배경음악 (파일 이름 그대로 두세요)
